# Gagnavinafélagið – Gagnabeiðnir

Velkomin í gagnabeiðnaskrá Gagnavinafélagsins.

Þetta vefsvæði (repo) hýsir utanumhald um allar formlegar upplýsinga- og gagnabeiðnir sem Gagnavinafélagið hefur beint til stjórnvalda á Íslandi. Markmiðið er að tryggja fullt gagnsæi um störf félagsins og svör stjórnvalda.

## Stefna um persónuvernd

Í samræmi við stefnu félagsins eru **nöfn almennra starfsmanna stjórnvalda afmáð** úr bréfaskiptum og skjölum (t.d. breytt í `[Starfsmaður Skattsins]`), en nöfn forsvarsmanna stjórnvalda, ráðherra eða annarra áberandi opinberra persóna haldast inni eftir atvikum. Nafni sendanda fyrir hönd félagsins er einnig haldið inni.
